# Local Development and Running Guide

This guide explains how to set up and run the CV Web Application locally on your machine.

---

## 📋 Prerequisites

Before you start, make sure you have the following installed on your system:
* **Node.js** (v18.0.0 or higher is recommended)
* **npm** (comes packaged with Node.js)

To verify if you have them installed, run the following commands in your terminal:
```bash
node -v
npm -v
```

---

## 🚀 Step-by-Step Setup

Follow these steps to get the application up and running:

### Step 1: Open the Project Directory
Navigate to the root directory of the application:
```bash
cd cv-webapp
```

### Step 2: Install Dependencies
Install the required packages and dependencies defined in `package.json`:
```bash
npm install
```
> [!NOTE]
> This command will create a `node_modules` folder in your project root containing all external dependencies.

### Step 3: Start the Local Development Server
Launch the Vite local development server:
```bash
npm run dev
```

Once the server starts, you will see output in the console similar to this:
```text
  VITE v8.x.x  ready in 300 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

### Step 4: Open in Browser
Open your web browser and navigate to:
👉 **[http://localhost:5173](http://localhost:5173)**

---

## 🛠️ Other Available Scripts

The following commands are also available in `package.json` for development and deployment:

| Command | Description |
| :--- | :--- |
| `npm run build` | Compiles and optimizes the project for production, outputting static files into the `dist/` directory. |
| `npm run preview` | Runs a local webserver to preview the production build generated by `npm run build`. |
| `npm run lint` | Runs ESLint to check the code for syntax or formatting issues. |

---

> [!TIP]
> During local development (`npm run dev`), any changes you make to the source code will automatically reflect in the browser immediately, without needing to manually refresh, thanks to **Hot Module Replacement (HMR)**.
